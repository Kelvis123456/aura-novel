# character-arc
## When to use
Use when a character feels static, a transformation feels unearned or abrupt, or the character serves the plot without an inner journey. It helps define the false belief at the core of the arc and map how it breaks.

## Core rules
- Treat the arc as the inner journey: the transformation from one sort of person to a different sort under pressure. The plot is what happens; the arc is who the character becomes. External plot supplies the pressure.
- Positive change arc components, in order: Lie (false belief about self or world, formed by a backstory wound, the "ghost"), Want (what they think they need, driven by the lie), Need (what would actually fulfill them, invisible at the start), Catalyst (story forces confrontation with the lie), Struggle (they resist), Truth (they accept reality and drop the lie), New Self (they act from the transformed perspective).
- Negative change arc (tragedy): Potential, Flaw, Temptation (the easy path that feeds the flaw), Descent (choices compound the flaw), Point of No Return (redemption offered and rejected), Consequence (the flaw destroys what the character valued).
- Flat arc: the character already holds the truth. Truth, World in Conflict, Testing (truth is pressured but holds), Influence (steadfastness changes others), Vindication. The character changes the world rather than being changed.
- Make want and need different. If the character wants exactly what they need, there is no tension; create a gap between the external goal and the internal need.
- Name the lie explicitly and trace it to a backstory wound. If the lie cannot be stated in one sentence, the arc has no foundation.
- Story events must directly challenge the lie. A change the events did not force is unearned.
- Real change is resisted. Write scenes where the character doubles down on the lie before letting go of it. A sudden flip without struggle reads as abrupt.
- Map arc to structure: Setup (lie established, want activated); First Plot Point (commits while still believing the lie); Rising Action (want pursued, lie reinforced); Midpoint (mirror moment, a glimpse of truth); Complications (lie vs. truth); Dark Night (lie fully fails, crisis); Climax (truth embraced, or rejected in tragedy); Resolution (new self demonstrated).
- Show change through external choices and actions, never by telling the reader the character changed (the Informed Arc).
- A mentor points a direction; the character must walk the path. Change caused only by being told the truth is the Magic Mentor failure.
- Trauma creates conditions; the arc is what the character does with it. Terrible events alone are not transformation.
- Even admirable protagonists need a blind spot. No flaw, no lie, no arc.
- Plant seeds early so the epiphany feels inevitable in retrospect; avoid the Instant Epiphany.
- Not every character needs a full arc; do not add transformation where it does not serve the story.
- Example lies: "I'm not worthy of love", "Power is the only protection", "Trust leads to betrayal".

## Diagnose
- Is the character meaningfully different at the end than at the start?
- What exactly does the character believe at the start that is false?
- Which backstory wound produced that belief?
- Does the character want something different from what they need?
- Did the story's events force this change, or does the author simply announce it?
- Where does the character resist, and do they ever double down on the lie?
- Is there a midpoint glimpse of truth and a dark night where the lie fully fails?
- Does the final act show the new self through a costly choice?

## How to apply to a draft
Reply in the same language as the passage. First give a short diagnosis: the arc type you detect (positive, negative, flat), the lie, want and need as far as the passage shows them, which beat the passage sits on, and which anti-pattern or gap you see (no transformation, unearned, abrupt, unclear lie, missing struggle, informed arc, instant epiphany). If the lie is not inferable, state your assumption inline instead of inventing silently, and do not impose an arc type the author did not choose. Then return a rewritten passage that fixes the main problem: replace announced change with a visible choice, add a resistance beat, or tie the event to the lie. Keep the author's voice, names, setting and plot facts. End by naming what you changed and why.
